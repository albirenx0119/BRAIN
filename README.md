# BRAIN（ブレイン）

**Brain Reconstruction, Alignment & Imaging for Neuroscience**

**バージョン: 1.0.1 · 更新日時: 2026-11-17 17:37:33 JST · 作者: Ren Y Sato**
Copyright © 2026 Ren Y Sato

## 全体の機能説明

BRAINは、連続した脳切片画像の位置合わせ、マルチチャンネル画像の確認、画像の重ね合わせ、3D画像スタックの構築を行うWindows用ソフトウェアです。

- PNG・JPEG・TIFF画像をフォルダ単位で読み込み、順番・解析対象・空スライスを設定できます。
- 自動位置合わせは、平行移動のみ、または平行移動と回転による剛体変換です。画像を局所的にゆがめません。
- 自動位置合わせ後に、1枚だけ、または全画像へ同じ移動・回転を追加できます。
- マルチページTIFFをチャンネル別に確認し、表示色・インテンシティ・合成チャンネルを調整できます。
- 切片を最大値投影してstackを作り、チャンネルをmergeできます。
- 画素サイズと切片間隔を使って3D画像スタックを構築し、3断面の連動表示や距離測定ができます。
- 画像・変換行列・解析条件・手動補正履歴を保存できます。

画像の読み込み・解析・表示・保存はPC内で行います。画像データは送信しません。初回の実行環境の導入、更新確認、creditからのメッセージ送信にはネット接続を使用します。

## 必要環境

- Windows 10 / 11、64-bit
- Python 3.10以降（推奨: Python 3.12）とTkinter
- Pillow 10.3以上13未満、NumPy 1.26以上3未満、opencv-python 4.8以上5未満
- .NET Framework 4.8（通常はWindowsに含まれています）
- 元データ・出力・表示キャッシュ・作業用データを保存できるディスク空き容量

大きなTIFFや多数の切片を扱う場合は16GB以上のメモリを推奨します。必要量は画像サイズとチャンネル数で変わります。自動位置合わせはCPUで計算します。時間やメモリを抑える場合は、縮小解像度を選んでください。

### 初回の実行環境の準備

起動時に必要な環境を確認します。不足がある場合は、**PCのPythonにインストール**または**仮想環境を作成**を選べます。仮想環境では、BRAINのフォルダ内の`.venv`にライブラリを導入します。どちらも解析はPC内で実行します。

Pythonがない場合は、確認後にwingetを使ってPython 3.12を導入します。キャンセルするとインストールせず終了します。

手動で準備する場合は、[Python公式サイト](https://www.python.org/downloads/windows/)からPythonをインストールし、インストーラーの**tcl/tk and IDLE**を有効にしてください。その後、BRAINのフォルダをPowerShellで開き、次を実行します。

```powershell
py -3 -m pip install -r .\function\requirements.txt
```

公式の導入案内: [Python](https://docs.python.org/3/using/windows.html)、[Pillow](https://pillow.readthedocs.io/en/stable/installation/basic-installation.html)、[NumPy](https://numpy.org/install/)、[OpenCV](https://docs.opencv.org/4.x/da/df6/tutorial_py_table_of_contents_setup.html)。wingetが使えない場合は、[Microsoftのアプリ インストーラー](https://learn.microsoft.com/windows/package-manager/winget/)を確認するか、Pythonを手動で導入してください。

## data

画面上部にBRAINの正式名称を表示します。

### フォルダの選択

**フォルダを選択**で画像フォルダを指定します。入力欄へフォルダをドラッグ＆ドロップすることもできます。対象は選択フォルダ直下のPNG・JPG・JPEG・TIF・TIFFです。サブフォルダは検索しません。

一覧には画像の順序、ファイル名、サイズ、解析に使用するかを表示します。複数選択して順序変更、先頭・末尾への移動、逆順、ファイル名順への復帰ができます。ドラッグでの順番変更にも対応します。

- **解析に使用**を外した画像は灰色になります。
- **空追加**は、選択画像の1つ上に空行を作ります。空行は自動位置合わせの対象になりません。
- 除外画像をGo analyze以降完全に無視するオプションをONにすると、その画像は画像送りにも現れず、3Dでの間隔も詰まります。
- 完全無視がOFFの場合、除外画像や空行の位置は保持し、align・stackでは**no image**と表示します。3Dではその位置を空けます。明示的な空行は完全無視をONにしても保持します。

フォルダと順序を確認したら、**Go analyze**を押します。この時点で解析対象を確定し、軽い表示用画像を準備します。dataの選択や順序を後から変更した場合は、再度Go analyzeで反映してください。解析中は元画像を別のソフトで編集・置換しないでください。元画像を変更した場合は、Go analyzeからやり直します。

### 保存した解析を再開する

Go analyzeを押すと、選択フォルダ内と、その直下の結果フォルダにあるBRAINの`params.json`、`*_stack_params.json`、3Dの`.npz`を確認します。見つかった場合は「メタデータを読んで解析済みデータを読み込みますか？」と表示します。

- **はい**：元画像との対応を確認し、保存されている画像順・除外・空行、アラインと手動補正、チャンネル設定、stack条件、3D表示・距離一覧を復元します。stack画像は保存条件から再計算します。NPZがあれば構築済み3Dデータを読み込み、なければ記録された3D条件から再構築します。
- **いいえ**：保存メタデータを使わずに画像を読み込み、解析しなおします。保存ファイル自体は変更しません。

復元すると、画像一覧は保存時の元画像一覧に戻ります。同じ場所の出力画像などは追加しません。元画像を選択してください。アライン後の出力画像に元画像用の変換を重ねて適用することはありません。元画像の名前・サイズ・更新日時が記録と一致しない場合は復元を止めます。移動する場合は元画像と保存メタデータを一緒に保管してください。古いメタデータは残っている情報の範囲で復元し、異なる画像や変換の保存結果どうしは混ぜません。複数の保存結果がある場合は、対応する最新のメタデータを使用します。任意の保存先がこの検索範囲外の場合は、メタデータを元画像フォルダかその直下の結果フォルダへコピーしてください。

新しく保存する各メタデータには、保存した時点の作業状態を含めます。変更を次回へ引き継ぐには、再度保存してください。

下部のログは新しいものが上に並び、エラーは赤い背景になります。画像を送るだけの操作はログに記録しません。

## align

### 自動位置合わせ

1. 基準にしたい画像を表示します。
2. **平行移動のみ**または**平行移動＋回転（剛体）**を選びます。
3. PNG/JPEGなどは基準色、マルチページTIFFは基準チャンネルを選びます。
4. **現在の画像を基準**または**全体最適化**を選びます。初期設定は現在の画像を基準です。
5. 計算解像度を指定し、**アラインを実行**を押します。

現在の画像を基準にする場合は、その1枚を固定して前後の切片を整列します。全体最適化では、特定の1枚を固定せず、複数の近傍画像の対応から全体を調整します。

**元解像度でアライン**と、最大辺を入力する**縮小解像度でアライン**を選べます。縮小時の初期値は1024pxです。保存時の画像は元解像度で、推定した移動・回転を全チャンネルへ共通に適用します。画面表示用画像は最大辺768pxで、計算用画像とは別です。

処理中は中央に進捗・経過時間・中止ボタンを表示します。NCCは重なりの確認に使う相関の指標です。高い値でも解剖学的に正しい整列を保証するものではないため、各切片を確認してください。

照合に失敗した場合は、位置が確定した別の近傍画像と再照合します。それでも合わない画像は**未成立**と明示して、その画像自身の元位置に残します。未成立画像は手動で補正してください。全体最適化で対応が途切れた場合は、以前の結果を保持してエラーを表示します。

### プレビューと手動補正

上段は入力画像、下段はアライン後です。最初・前へ・次へ・最後、または画像番号で移動します。元解像度で表示したい場合は**生データを表示**をONにします。最大辺8000pxを超える生画像は、切り替え・画像送り時に進捗を表示します。

- ホイール: 拡大縮小
- ドラッグ: 平面移動
- **元の位置に戻す**: 表示の移動・拡大縮小をリセット
- 入力とアライン後の表示範囲は連動します。

マルチページTIFFはチャンネルを横並びに表示します。チャンネル画像のダブルクリックで1チャンネル表示へ切り替え、再度ダブルクリックすると横並びへ戻ります。**merged**では、チェックしたチャンネルを合成します。基準チャンネルは赤枠、固定した基準画像はアライン後に黄色枠で示します。

アライン後の移動・回転は、**この画像だけ**または**全画像に同じ量**を選びます。ボタンは長押しで連続操作できます。平行移動のみで計算した場合は回転操作を無効にします。1つ戻す・補正をすべてやり直すにも対応します。

表示色はGray・Red・Green・Blue・Magenta・Cyan・Yellow、または**color pick**で選べます。RGB値を直接編集でき、カスタム色は16進数コードで表示します。インテンシティはチャンネルごとに下限・上限を調整できます。選択中は矢印キーで1、Shiftで10、Ctrl＋Shiftで100ずつ変更します。

2D表示のスケールバーは表示ON/OFF、長さ、文字、色を指定できます。長さの初期値は50µmです。実寸表示には正しい画素サイズが必要です。

## save

保存先、保存名、フォルダ作成の有無、保存する内容、画像形式を指定します。保存先の初期値は解析画像のフォルダです。画像ファイルには**保存名_**をprefixとして付けます。

- **画像**と**移動・回転のメタデータ**を、必要なものだけチェックします。
- PNG・TIFF・JPEGから出力形式を選べます。
- マルチチャンネルTIFFのPNG/JPEG出力では、全チャンネルを合成するか、チェックしたチャンネルだけ合成するか選べます。
- 合成画像はalignの表示色とインテンシティを使った8-bit RGBです。対応する元の数値型・ページ構成を保持する場合はTIFFを選んでください。

**params.json**は常に保存します。入力フォルダ、画像順、基準、色・チャンネル、計算条件、各画像の変換、未成立の情報、手動補正履歴、出力と元画像の対応を記録します。

**フォルダを作成**がONで同名フォルダが存在する場合は、上書きするか確認します。上書き時は今回と同名の出力を置き換え、その他のファイルは残します。元画像への上書きは行いません。保存先の同名画像には、入力識別子を付けて出力名を区別します。

## stack

### raw tiff

解析画像と拡張子を除いて同名のTIFFを、フォルダ単位で対応付けます。名前・枚数・重複が一致しない場合は確認します。dataでマルチページTIFFを読み込んだ場合は、同じフォルダが選択された状態で開始します。

**TIFFを読み込み**を押すとチャンネルを横並びで表示します。画像送りはalignと同じです。アライン結果があれば反映し、表示色・インテンシティも引き継ぎます。チャンネルごとに色と表示範囲を調整できます。

### stack

チャンネルごとに**all**、または**select**を選び、範囲を入力してstackします。selectでは`1~3,5,9`のように、範囲と個別指定を組み合わせられます。画像番号はdataの並びに対応します。

stackは、指定切片の**最大値投影（MIP）**です。実行時のインテンシティ設定を使用します。下限・上限はalignから引き継ぎますが、スライダーの最小・最大は元画像固有の値を使います。表示範囲や対象切片を変えたら、再度stackしてください。全チャンネルのstack後はmergeへ移動します。

### merge

stackしたチャンネルを合成表示します。表示するチャンネルをチェックボックスで選べます。stackしていないチャンネルは、先にstackしてください。

### save

stack内のsaveでは、保存先、作成するフォルダ名、保存する画像名を指定します。ここでの画像名はprefixではなく、保存名そのもののベースです。

stack画像とmerge画像の保存を個別に選べます。PNG・TIFF・JPEGを指定し、スケールバーのON/OFF・長さ・文字・色も設定できます。スケールバーは初期状態でON、50µmです。

保存画像は元のXY解像度で投影した8-bit RGB画像です。チャンネル名または色、アライン使用の有無、stack範囲をファイル名へ記録します。例: `sample_ch1_aligned_stacked-1to3-5.png`。mergeは先頭に`merged_`を付け、各チャンネルの条件も末尾へ記録します。条件の詳細はJSONにも保存します。

## 3D reconstruction

### 構築条件

画素サイズX/Y、切片間隔Z、計算サイズ、画像順の前後方向を設定して**3D構築**を押します。初期状態ではアライン・手動補正後の画像を使用します。元画像で比較する場合は**アラインしていないデータを使用**をONにします。

画素サイズX/Yは、画像フォルダの`pixel_sizes*.csv`を優先し、なければTIFFの標準解像度タグ・ImageJ情報・OME-XMLから読み込みます。単位はµmです。情報がなければ手入力してください。初期値の1は仮値で、測定前に実寸を確認する必要があります。Zには実際の切片間隔を入力します。

画像順は**前→後（A→P）**または**後→前（P→A）**を選びます。APはげっ歯類の前後軸、ML（X）は画像横方向、DV（Y）は画像縦方向です。初期表示はAが左手前、Pが右奥です。Bregma基準の絶対座標を推定する機能ではありません。

### 表示と確認

3D表示には、移動・回転した画像そのものをAP方向へ並べます。二値化・輪郭抽出・表面メッシュ化は行いません。構築画像は指定したサイズへ縮小した表示用データで、切片間の補間は行いません。

- 通常のドラッグ: 平面移動
- Shift＋ドラッグ: 回転
- ホイール: 拡大縮小
- 視点ボックスの面・辺・角: 指定方向から表示
- 3D内の画像や冠状断XYをクリック: 他の断面を同じ場所へ移動
- 画像のない背景をクリック: 選択切片の黄色枠を解除

チャンネルと切片をチェックボックスで表示・非表示にできます。チャンネル別の不透明度、選択切片の強調、A側から切片を隠す操作にも対応します。非表示にしても、構築データ自体は削除しません。

**AP方向の表示間隔**は表示だけを変更します。構築時の実際のZ間隔、距離測定、保存済みの物理情報は変わりません。3D表示のリセットで初期視点へ戻せます。

冠状断XYと2つのAP縦断は連動します。断面スライダーを選択すると、矢印キーとホイールでも移動できます。各断面にはスケールバーを表示でき、初期値は50µmです。

### 距離測定と保存

距離測定をONにし、3Dまたは断面で2点をクリックすると、距離とML・DV・AP各方向の差をµmで表示します。表示上の間隔・拡大縮小には依存しません。未校正の場合は参考値として扱ってください。

3DデータはNPZ形式で保存します。構築画像、チャンネル情報、有効範囲、物理間隔、AP方向、表示条件、解析条件、測定点と距離を記録します。

### 距離を一覧に残す

距離測定をONにし、画像上の2点をクリックすると「距離1」「距離2」…として距離測定ボックスに自動追加します。名前は一覧の入力欄で変更できます。各行のチェックで、その距離を3D・断面に表示するか選べます。×で個別削除できます。「測定中の点を消去」は入力中の点だけを消し、保存済みの距離一覧を残します。

距離一覧は3DのNPZと各保存メタデータに含まれ、解析再開時に復元します。「距離一覧を保存」からJSONまたはCSVとして別途保存することもできます。JSONには測定点・実寸座標・距離成分・校正確認情報を含めます。CSVには名前・表示状態・距離・ML/DV/AP成分・2点のZYX座標を記録します。測定点のZYXは、0始まりの構築ボリューム座標です。距離は表示用のAP間隔ではなく、構築時の実際の画素サイズと切片間隔から計算します。

チャンネル別の不透明度はスライダーと隣の数値欄（0〜100%）の両方で変更できます。選択中のチャンネルのチェック欄は、そのチャンネルの色でハイライトします。

## 共通操作・困ったとき

表示画像の右クリックメニューから、形式を指定して表示画像をコピーできます。コピーには表示上のスケールバーなどを含みます。原画素データの保存にはsaveを使ってください。

- **起動できない**: ZIP全体を展開し、BRAIN.exeとfunctionの配置を確認してください。`logs/startup.log`で起動エラーを確認できます。
- **処理が遅い・メモリ不足**: 縮小解像度や小さい3D計算サイズを選び、他の大きなソフトを閉じてください。
- **位置合わせが合わない**: 基準チャンネルや基準画像を変え、結果を1枚ずつ確認してください。損傷・大きな形状差・斜め切りを剛体変換だけで補正することはできません。
- **スケールバーや距離が合わない**: X/Y画素サイズとZ切片間隔、CSV/TIFFの単位を確認してください。
